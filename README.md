# Nicholas' Code Editor

A HTML editor and Macro Microcontroller BASIC editor web application with a simulator, renderer and sharing URL generator, so you can share and embed your HTML code and download your BASIC programs easily!

Note: Macro Microcontroller BASIC Web Editor currently only supports GPIO statements in the simulator. All other statements are supported on the hardware. More support will be added soon!

Try the editor at <a href="https://editor.nicholaslim.me">https://editor.nicholaslim.me</a> or <a href="https://nicholas1023.github.io/editor">https://nicholas1023.github.io/editor</a>!
